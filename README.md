# MongBB Lightbox Simulator

Public static distribution of the interactive 200 × 200 × 50 mm lightbox simulator. Includes the full 64 × 64 editor, optics controls and local Natural Earth land data.

All simulations run in the browser. No ChatGPT login, OpenAI API, external map download or local server is required for visitors. Optical properties are adjustable assumptions, not calibrated hardware predictions.

Third-party runtime licenses are included in third-party-notices.txt. Natural Earth land data is public domain; source: https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/
