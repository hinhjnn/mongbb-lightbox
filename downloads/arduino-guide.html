156 個城市，一塊 64 × 64 燈板。

ESP32-WROOM-32 · P2.5 64×64 · 1/32 scan · USB 115200 baud

程式包含 559 個底圖像素、156 個具名城市、164 個互不重疊的城市控制點；其中 8 個城市各佔 2 點。網站亦可新增城市，每個城市最多 8 點、合共最多 256 個城市。

左上角是 (0,0)，x 向右、y 向下，範圍均是 0–63；index = y * 64 + x。原圖約 2:1，等比例縮至中央 64×32（y=16–47），上下保留黑色空間。實體板仍然是 64×64、160×160 mm。

這是按使用者參考圖編排的裝飾地圖。城市經美術移位以分開密集地區；多點只表示一組控制區域，不代表城市面積、行政邊界或精確 GPS 投影。城市可在網站改名、移位或加點。

1. 先在網站試，不用接板

  1. 開啟「城市編輯器」，按「載入城市地圖模板」。預設香港、東京、倫敦亮燈。
  2. 搜尋中英文城市名，或在點陣圖按有框線的點，選擇城市。
  3. 修改開關、0–255 亮度、顏色。城市關閉會回到淡藍底圖；把「城市底圖亮度」設為 0，才會完全黑色。
  4. 點空格後可「移動主點到此」、「將此點加入城市」或「新增城市」。不同城市不共用同一粒 LED。
  5. 右側 RGB Matrix 控制可選「呼吸」及週期。呼吸是整幅 RGB 圖案共用，城市仍保留各自亮度與顏色；不是每個城市獨立計時。
  6. 下載「城市設定 JSON」保存名稱、區域及顏色，日後可匯入繼續編輯。頁面重新整理不會自動保存。下方一般「設定 JSON」只保存模擬器及像素，不包含城市命名資料。

金色及白色框線只供編輯定位，不傳到燈板。城市編輯器持有自己的模板；若用原始像素工具改圖、載入 A/B 或其他設定，再改城市控制，會重新套用城市模板。

2. Arduino IDE 開啟與編譯

  1. 下載並解壓 完整程式 ZIP。保留 MongBBCityMap 資料夾及裏面的全部檔案，雙擊 MongBBCityMap.ino。
  2. Arduino IDE 的 Boards Manager 安裝 esp32 by Espressif Systems 2.0.17。若未找到 ESP32，在 Preferences 的 Additional Boards Manager URLs 加入：https://espressif.github.io/arduino-esp32/package_esp32_index.json。
  3. Library Manager 安裝 ArduinoJson 7.4.3、ESP32 HUB75 LED MATRIX PANEL DMA Display 3.0.14、Adafruit GFX Library 1.12.1，接受 GFX 所需 Adafruit BusIO 依賴。若找不到指定 HUB75 版本，可用其 官方 release ZIP，經 Sketch → Include Library → Add .ZIP Library 安裝。
  4. 選 Tools → Board → ESP32 Arduino → ESP32 Dev Module，PSRAM Disabled。其他選項先用板型預設值；ESP32-WROOM-32 模組名稱本身不確定你開發板的 Flash 大小。
  5. 按 Verify 編譯。提供的兩個韌體設定已用 Arduino-ESP32 2.0.17 編譯通過；驗證工具是 PlatformIO，未聲稱在你的 Arduino IDE 或實物板上測過。
  6. 只試 USB 時，先把 BoardConfig.h 內預設 #define MONG_PANEL_ENABLED 1 改成 0。USB 協定會工作，但 HUB75 不輸出。
  7. 按下節核對接線與供電後，燈板版本使用 MONG_PANEL_ENABLED 1。選正確 USB Port，Upload。需用可傳資料的 USB 線；某些板要按住 BOOT 開始上傳，再放開。

想燒錄自己編輯的城市：在網站下載「我的城市座標 Cities.h」，覆蓋同名檔後重新 Verify / Upload。它包含名稱、座標、顏色、開關、城市亮度與底圖亮度；呼吸及模擬材料不在這個檔，呼吸用 Serial Monitor 命令或 USB 設定。若板內已有保存圖案，上電會優先還原保存圖案；輸入 defaults 才載入新 Cities.h 預設，再輸入 save 保存。

3. 接線參考：需對照你的燈板 IN 接口

目前只確認 P2.5、64×64、32S 和 ESP32-WROOM-32。驅動 IC、接口腳序、電源額定值仍未確認。SHIFTREG 是可調假設；FM6126A 等 IC 要用相符設定。僅有 1/32 scan 並不能保證相容。

HUB75E 訊號ESP32 GPIO
R1 / G1 / B125 / 26 / 27
R2 / G2 / B214 / 32 / 33
A / B / C / D / E23 / 19 / 18 / 17 / 16
LAT / OE / CLK4 / 21 / 22
GNDESP32 GND 與燈板電源 GND 共地

按訊號名稱接到燈板 IN，不要單靠插頭外觀猜腳位。64×64 1/32 需要 E 線。這是 WROOM 參考腳位，其他模組要重核。

燈板用符合其標示電壓、電流需求的獨立電源；常見 HUB75 板是 5V，但以你的板為準。USB 只連 ESP32，不要經 ESP32 的 3.3V、USB 或細訊號線供應整塊燈板。ESP32 訊號是 3.3V；若燈板要求 5V 邏輯，用合適的 3.3V→5V 緩衝／電平轉換（例如符合要求的 AHCT 方案），不要把 5V 訊號反接入 ESP32。關電後接線。

韌體先限制 MONG_BRIGHTNESS_CAP = 32（0–255 輸出設定）。這不是電流限制、量度亮度或電源保護保證。8-bit PWM 色深、10 MHz 時脈及輸出上限均是可調初始設定；色差、最低可見亮度、刷新與功耗須實物量度。

4. 最容易試：Serial Monitor

設定 115200 baud，行尾選 Newline。城市 ID 區分大小寫；例如 HongKong，不是中文名稱。每次輸入一行：

map 0
city HongKong on 160
city Tokyo on 100
city London on 200
city Tokyo off
breathe 4
steady
save
命令作用
list / help列出全部城市 ID、名稱、座標／幫助
city HongKong on 160該城市所有點用 160/255 邏輯亮度開啟
city Tokyo off回到底圖；map 0 時完全黑色
point 50 35 on 180單點；不改城市區域定義
map 32 / map 0淡藍底圖／關底圖，按韌體城市表重建
breathe 4全圖 4 秒一個呼吸週期，可用 2–30 秒
steady / pause / play停止呼吸／凍結動畫／繼續動畫
off整塊 RGB Matrix 關閉，不更改已保存設定
defaults載入目前 Cities.h 的預設
save保存目前圖案，下次開機還原

程式內亦可呼叫 setCity("HongKong", true, 160); 或 setPoint(50, 35, true, 180);。座標、預設顏色及多點區域在 Cities.h，底圖在 WorldMap.h。

保存需要 LittleFS。程式不會自動格式化既有儲存區；全新板若回覆 storage unavailable，可在確認板內沒有要保留的檔案後，手動輸入 format-storage ERASE，再 save。這會清空此韌體使用的 LittleFS 分區。刷入程式本身亦會覆蓋板上的舊應用程式，請用適合本專案的 ESP32。

5. 網站經 USB 即時改燈

  1. 在電腦 Chrome 開啟 MongBB 網站，或本機 localhost。手機可編輯及下載，但此流程不依賴手機 Web Serial 支援。
  2. 關閉 Arduino Serial Monitor 及其他佔用埠的程式。
  3. USB 接 ESP32，按「連接 ESP32」，由你選裝置。網站會確認韌體版本及 64×64 規格，不會自動燒錄。
  4. 載入城市模板，再按「傳送目前圖案」。想每次修改自動傳送，可勾「即時同步」。
  5. 必須看到 ESP32 確認接收，才表示傳送完成；USB 檢查版會清楚顯示輸出關閉。完整圖案需幾秒，後續只傳變更行。
  6. 需要上電還原時按「儲存到 ESP32」。USB 斷線不會自動熄燈；ESP32 仍有供電便繼續最後圖案。要熄燈先按「實物全關」。

USB 傳送目前的像素圖及 RGB 效果，不會改板內編譯的城市名錄；新名稱／區域要同步到 Serial Monitor 的 list，請替換 Cities.h 再燒錄。材料、CCT、曝光、Bloom 是模擬器設定，沒有傳到硬件。螢幕顏色與實物未經色彩或光度校準。

6. 已驗證與待驗證

原始碼包含單元測試、真正 C++ 控制核心測試、TypeScript↔C++ 全像素比對、USB 斷線／逾時／取消測試，以及桌面與窄屏瀏覽器驗收腳本。兩個 ESP32 設定已用固定版本 Arduino 框架編譯。

未連接你的實物 ESP32 或燈板；未驗證真實驅動 IC、接線、顏色、亮度、耗電或刷新。 若畫面錯行、倒置或黑屏，先核對 IN／E 線／腳位／驅動 IC 與電源，勿靠加亮度解決。
